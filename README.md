# Linux Learning Simulator

## What this does
Interactive simulator to practice real Linux commands in real-world scenarios.

## Why I built this
As a Technical Support Engineer, I wanted hands-on learning instead of theory.

## Features
- 40+ real-life scenarios
- Command-based learning
- Explanation mode

## Tech Used
- HTML, CSS, JS

## What I learned
- Linux command flow
- Scenario-based troubleshooting
- UI/UX structuring

## Future Improvements
- Add backend
- Save progress
- Difficulty levels
